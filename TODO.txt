Wenn ich die Sprache des Betriebssystem auslesen muss wo packe ich das hin?

FastTheme?
FastDisplay (PPI, resolution und so)
Kurz und präzise, aber mit der nötigen architektur‑Tiefe:

🧩 OS‑Sprache auslesen → gehört NICHT in FastTheme und NICHT in FastDisplay
Die Betriebssystem‑Sprache ist kein Theme‑Aspekt  
→ FastTheme = Appearance (DWM, Mica, Borderless, Shadows, Titlebar)

Die Betriebssystem‑Sprache ist kein Display‑Aspekt  
→ FastDisplay = Hardware‑Display (PPI, DPI, Resolution, Refresh‑Rate, Orientation, Hotplug)

Beides wäre falsch.

🎯 Die OS‑Sprache ist ein System‑Parameter → eigenes Modul
Die OS‑Sprache gehört in ein Modul, das:

System‑Locale

UI‑Language

Input‑Language

Keyboard‑Layout

Region / Culture

Time‑Format (24h/12h)

Number‑Format

Calendar‑Format

verwaltet.

Das ist System‑Level, nicht Theme, nicht Display.

✔️ Richtiger Ort: FastSystem / FastCore / FastEnvironment
Der präziseste Name im FastJava‑Ökosystem wäre:

FastSystem
→ OS‑Informationen
→ Locale / Language
→ Region
→ Time / Date Format
→ Environment Variables
→ System Paths
→ User Directories
→ OS Version
→ Build Number

Oder wenn du es noch granularer willst:

FastEnvironment
→ Locale
→ Language
→ Region
→ Culture
→ Input‑Method
→ Keyboard‑Layout

🧠 Warum ein eigenes Modul?
Weil OS‑Sprache global ist:

beeinflusst UI‑Text

beeinflusst Formatierung

beeinflusst Logging

beeinflusst Date/Time Parsing

beeinflusst File‑Explorer‑Labels

beeinflusst CREAM‑Zeitachsen‑Formatierung

beeinflusst FastUI‑Text‑Rendering

beeinflusst FastOverlay‑Labels

beeinflusst FastRobot‑Keyboard‑Mapping

Das ist systemisch, nicht visuell und nicht hardware‑bezogen.
